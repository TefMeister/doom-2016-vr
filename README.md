# doom-2016-vr

> ### ⏸️ Paused (2026-09-17)
>
> **There is already a VR mod for DOOM (2016): [KHARVOX](https://github.com/CactusVRStudios/KHARVOX/releases)** by CactusVRStudios, out now, v0.9 beta (released 2026-09-13). Use that one.
>
> Work on this project is paused. If it resumes, it will build on top of KHARVOX (so KHARVOX would be required), rather than compete with it.

**DOOM (2016)** — a flat-to-VR modding project.

Consolidated on 2026-08-30: each folder below used to be one of this project's
six separate repositories (`doom-2016-vr-mod`, `-dev-archive`, and so on)
and carries its full git history.

| Folder | What lives here |
| --- | --- |
| [`mod/`](mod/) | Release packaging and player-facing docs. The releases themselves are on this repo's [Releases page](https://github.com/TefMeister/doom-2016-vr/releases). |
| [`dev-archive/`](dev-archive/) | The live mod source, tools, and recon evidence. |
| [`modding-notes/`](modding-notes/) | A dated ledger of findings, decisions, and lessons. |
| [`engine-research/`](engine-research/) | The engine dossier: distilled truth about this game's engine, dead ends included. |
| [`external-research/`](external-research/) | Curated public research: sources, techniques, and prior art. |

Knowledge shared across every project lives in
[flat-to-vr-cross-engine-research](https://github.com/TefMeister/flat-to-vr-cross-engine-research)
and [flat-to-vr-RE-toolkit](https://github.com/TefMeister/flat-to-vr-RE-toolkit);
the account map is [TefMeister/INDEX.json](https://github.com/TefMeister/TefMeister).

This is personal, non-commercial fan modding; no original game assets are
redistributed. See the `CONTRIBUTING.md` and `CREDITS.md` files (at the root
and inside the folders) for the full terms and every source credited.
